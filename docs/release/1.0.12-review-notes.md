# BAK MX 1.0.12: What's New and App Review notes

## What's New (App Store)
Where to Ride
- Riding areas next to the tracks: off-road parks and national forest trails, with what you can ride and how wide,
  passes, season, hours and rules from the official pages.
- Trail maps for national forest areas: Forest Service trail lines colored by width, with each trail's name and season.
- Near me, search by name or town, or pick a state.
- Ride here today starts a practice day there, with Ride Day mode, check-ins and Ride safety.

## Notes for App Review
- Where to Ride: Home → More → Where to Ride. Pick "Riding areas", then "Ocala National Forest OHV Trail System" →
  "Trail map". The map is Apple Maps with Forest Service (public domain) trail lines drawn on it.
- Location: "Near me" asks for location while using the app, only to sort the list nearest first. The location stays on
  the phone. The when-in-use location text now mentions this alongside Ride safety. No new background use.
- "Open in onX" is a plain link to onX's public website. There is no partnership or shared data.
