## Method

The extractor that produced the 2026-10-10 rows was not kept, so it was rebuilt and is now in `scripts/manual-textlayer/`.

1. Two page layouts: manuals headed "TECHNICAL DATA" / "TECHNICAL SPECIFICATIONS" (to model year 2025) and manuals headed
   "Technical specifications" (new authoring system, 2025 on). Indentation and the value column decide group, label and value.
   Rows of one table are 14.4 pt apart; lines within a row are closer than 12.5 pt. That gap decides what is a continuation.
2. Service schedule: a mark sits 7.3 pt left of the right edge of its column header; open circle = one-time, filled = periodic.
   Checked on every page: header order must be consistent and every mark must land on a header within 3 pt, or the table is not stored.
3. Validity: every printed note (section heading, group, label) is matched against the US standard model
   (`validity.py`: "All SX models", "125 XC US", "SX-F EU/US, XC-F US", "All SX-F except US", "Big wheel", ...).
   A note that looks like a validity note but is not understood drops its rows. Factory and other special editions are excluded.
4. A path printed with two different values for one bike is dropped. A damper group is stored only complete (Comfort, Standard, Sport)
   and only when the same three values appear together in the adjustment section of the same manual.
5. The cover must name the model.
6. Rows go to the database as before: `private.kg` rebuilds the table and stores it only when its SHA-256 equals the hash computed
   where the PDF was read. Staged, evidence gate, then verified.

## Checks that were run

- Regression against the 2026-10-10 rows on a manual both passes read (KTM 250 XC-F 2027): same fork, shock and engine values.
- After every parser change all bikes already loaded in this pass were rebuilt and compared. That found and fixed, in place:
  KTM 125 SX and 150 SX 2020 (a tire pressure stored under "Brake discs - wear limit / rear"), KTM 125 SX 2024 (spring rates stored
  without their "Spring rate" group) and three cosmetic value formats. The 35 two-stroke bike-years were then re-verified
  against the current extractor by hash (35 of 35 match).
- 60 values were dropped by shape checks (unbalanced brackets, label running into prose, value starting with a bracket).

## Left out on purpose

- Second-gear ratio on the 2025-2027 KTM 85 SX manuals: the PDF prints a clock time ("2:28 PM") where the ratio belongs.
- Carburetor tuning tables by altitude and temperature (not yet read; the base jetting and the sand setting are stored).
- Tightening-torque rows the manual splits by model inside one row.
- Fuses where two fuse rows share one label.
