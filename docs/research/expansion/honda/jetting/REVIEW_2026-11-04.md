# Honda CRF150R jetting charts (2021-2026), 2026-11-04

Honda's CDN refuses automated downloads, so Kyle downloaded the six Competition Handbooks in his own browser and attached
them. Nothing was fetched around the block. The PDFs are not stored here; `charts.jsonl` holds the SHA-256 of each one.

- Read with `scripts/manual-textlayer/honda_jetting.py` (`pdftotext -layout`): page 3-20 "Standard muffler" and page 3-21
  "Optional Muffler" (AMA noise-compliant muffler), each 5 elevation bands x 7 temperature columns, with pilot screw,
  slow jet, needle clip, jet needle and main jet per cell. Every row had to carry exactly 7 values; °C/°F headers and
  metre/foot labels were checked against each other.
- The charts are identical in all six handbooks (2021-2026).
- Second read: every cell of the standard chart (pilot screw, clip, jet needle, main jet) matches the 2020 chart already on
  file, which an earlier pass read from the 2020 owner's manual.
- Loaded: CRF150R 2021-2026, 70 rows each (35 standard, 35 optional muffler). The charts cover the CRF150R and CRF150RB.
