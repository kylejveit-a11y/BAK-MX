# Fuel, jetting and weather sources (`shared/fuel-weather.ts`, version `mx-fuel-weather-1`)

Research pass on 2026-11-07. Public pages only; nothing behind a paywall, login or bot check was read, and no block was
worked around. Every fact in the module is in BAK's own words; no source text is pasted. Rider-facing text names bike,
fuel and part makers only. Magazines, testers, retailers and riders are never named to riders. Each id below matches
`FUEL_WEATHER_SOURCES` in the module, and `tests/fuel-weather.test.ts` checks that every id and URL appears in this file.

Accessed date is 2026-11-07 unless the row says otherwise. "Published" is given where the document shows one.
The air numbers (density altitude, air density, carb mixture change) are not from any source: they are computed by
`airDensity` / `airChange` in `shared/engine-physics.ts` and marked `bak-engineering` in the module.

## Gaps and refusals

- Yamaha's YZ tuning chapter (symptom table, throttle-opening chart, humidity line) was not in any copy the tool could read; the
  page-by-page host returned only its contents page. Not worked around.
- Kawasaki's jetting correction-factor chart (KX85 tuning chapter) was past the readable part of the PDF.
- A bot-protection page blocked a hosted Yamaha YZ450F service manual (intake air pressure/temperature sensors). Not worked around.
- Honda's "Fuels containing alcohol" web manual page and Kawasaki's Connect page were blocked by the fetch tool's provenance rule.
- No maker page found that lists EFI lean symptoms after an aftermarket exhaust; that line is BAK engineering.
- Not found: Suzuki, Triumph, GasGas and Husqvarna fuel grade pages; KTM two-stroke TBI premix ratio; Kawasaki DFI coupler names
  for pre-2024 KX. The bike's own verified claims cover these when on file.
